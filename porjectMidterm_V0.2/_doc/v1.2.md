# v1.2 訓練優化 + Web 互動介面

版本日期：2026-06-03

## 改版重點

依據 `task_1.1.md` 分析，針對 Loss 高原卡在 0.766 的問題進行全面診斷與修復，
主要瓶頸為 embed_size/hidden_size 過小（64）與學習率過低（5e-5），
同時補上訓練流程中的標準基礎設施，並依據 `task_1.2.md` 建置 Web 互動介面。

## 新增功能

### 1. 驗證集分割（main.py）

- 使用 `torch.utils.data.random_split` 進行 90/10 隨機分割（seed=42 確保可重現）
- 訓練與驗證分別使用獨立的 DataLoader
- epoch 結束時計算 validation loss，作為模型選擇與 early stopping 的依據

### 2. ReduceLROnPlateau 學習率排程器（main.py）

- 監控 validation loss，`factor=0.5`，`patience=10`
- Loss 連續 10 回合未改善時，學習率減半
- 幫助模型跳脫局部極小值

### 3. 梯度裁剪 Gradient Clipping（main.py）

- `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`
- 在 `loss.backward()` 之後、`optimizer.step()` 之前執行
- 防止 LSTM 訓練常見的梯度爆炸問題
- 每 epoch 記錄實際 gradient norm 數值

### 4. 雙軌訓練日誌系統（main.py）

- **CSV 日誌**（`training_log.csv`）：每個 epoch 一行，包含
  - epoch, train_loss, val_loss, lr, grad_norm, timestamp
  - 方便 pandas/matplotlib 後續分析與繪圖
- **純文字日誌**（`training_log.txt`）：人類可讀格式，含啟動參數摘要表頭
- 兩種格式同時寫入，互為備份

## 超參數變更

| 參數 | v1.1 | v1.2 | 原因 |
|------|------|------|------|
| `embed_size` | 64 | 256 | word-level 詞彙量 3924，64 維嚴重 rank-deficient |
| `hidden_size` | 64 | 256 | 配合 weight tying 強制相等 |
| `dropout` | 0.2 | 0.1 | 模型容量已不足時降低正則化力度 |
| `learning_rate` | 5e-5 | 1e-3 | Adam 從頭訓練的標準 LR（原值過低 20 倍） |
| `total_epochs` | 15000 | 500 | 實際收斂不需如此多回合 |
| `batch_size` | 64 | 64 | 維持不變 |

## 模型架構變更

- embed_size/hidden_size 從 64 提升至 256，參數量約增加 4-16 倍（依層別）
- 舊版 `model_checkpoint.pt` 因維度變更不相容，已移至 `archive/`
- `checkpointHistory/` 同時移至 `archive/checkpointHistory/`

### 5. 詞彙表獨立儲存（main.py + app.py）

- `main.py` 在建立詞彙表後同步儲存 `vocab.json`
- `app.py` 載入 checkpoint 時，優先尋找同目錄下的同名 `.json` 檔
- 若找不到，則回退使用根目錄的 `vocab.json`
- 解決 checkpoint 不包含 vocabulary 的問題

### 6. Web 互動介面（app.py + static/index.html）

- **後端**：FastAPI 伺服器，提供 RESTful API
  - `GET /api/models`：掃描 `checkpointHistory/` 回傳可用模型清單
  - `POST /api/generate`：接受參數進行文字接龍推論
- **前端**：Vanilla HTML/CSS/JS 雙欄版面
  - 左側控制面板：模型選擇、Temperature 滑桿、Top-k 滑桿、生成長度
  - 右側聊天區：對話記錄 + 輸入框 + 送出按鈕
- **LRU 模型快取**：最多快取 3 個最近使用的模型，避免重複載入

### 7. 架構自動推斷（app.py）

- `infer_model_arch(state_dict)`：從 state_dict 的 tensor shape 自動推斷
  - vocab_size、embed_size、hidden_size、num_layers
- 任何 .pt checkpoint 不需額外 metadata 即可載入
- 相容 embed_size=64（舊版）與 embed_size=256（新版）架構
