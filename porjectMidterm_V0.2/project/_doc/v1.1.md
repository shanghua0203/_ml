# v1.1 專業化升級：詞層級 + Weight Tying + GPU + Top-k

版本日期：2026-06-02

## 改版重點

本次升級依據 `optimization.md` 的四項技術優化需求，
將 LSTM 語言模型從「字層級」提升到「詞層級」，
並加入多項深度學習領域的標準技術。

## 新增功能

### 1. jieba 詞層級分詞（text_processor.py）

- 導入 `jieba.lcut()` 將中文句子從「字層級」改為「詞層級」切分
- 新增 `tokenize(text)` 函數封裝 jieba 分詞邏輯
- 詞彙表從「單一字元」變成「詞語」，語義更完整

### 2. <UNK> 未知詞防呆（text_processor.py）

- 在字典中加入 `<UNK>` 特殊標記，固定編號為 0
- `text_to_ids()` 改用 `dict.get(word, UNK_ID)`，遇到沒看過的詞自動用 `<UNK>` 代替
- 防止程式因為字典查不到而報錯當機

### 3. Weight Tying 權重共享（model.py）

- 新增 `tie_weights` 參數（預設 True）
- Embedding 層與 Linear 輸出層共用同一組權重：`self.fc.weight = self.embedding.weight`
- 啟用 Weight Tying 時，`embed_size` 自動等於 `hidden_size`
- Linear 層在啟用 Weight Tying 時不設 bias（`bias=False`）
- 減少模型參數量，提升學習效果

### 4. GPU / MPS 自動偵測（text_processor.py + main.py）

- 新增 `auto_device()` 函數，依序檢查 CUDA → MPS → CPU
- 訓練時將 model 和 batch 資料搬移到對應裝置
- 不再只綁死在 CPU 上執行

### 5. Top-k 採樣（main.py）

- 新增 `top_k_filter()` 函數：保留機率最高的前 k 個選項，其餘設為 -inf
- `generate_text()` 新增 `top_k` 參數（預設 5）
- 先 Top-k 過濾 → 再 Temperature 縮放 → Softmax → Multinomial 抽樣
- 避免模型產出無意義的火星文
