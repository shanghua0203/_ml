# 優化專案中的參數設定，落實「參數集中化」的原則。將 `comparison_agent.py` 中寫死的併發限制（Semaphore）提取到 `config.py` 中作為環境設定檔的一部分。

## 需要修改的檔案與步驟如下：

1. 編輯 `src/core/config.py`：
   - 在 `Settings` 類別的「搜尋設定」區塊中（大約在 `SEARCH_RESULTS_COUNT` 的下方），新增一個型別為 int 的變數 `MAX_CONCURRENT_SCRAPES: int = 3`，並加上註解「最大併發抓取數量」。

2. 編輯 `src/agents/comparison_agent.py`：
   - 在 `compare` 方法中，找到這行程式碼：`semaphore = asyncio.Semaphore(3)`。
   - 將寫死的數字 `3` 替換為設定檔中的變數，修改為：`semaphore = asyncio.Semaphore(settings.MAX_CONCURRENT_SCRAPES)`。
   
## 請確保修改後的程式碼沒有語法錯誤，且 `settings` 已經正確從 `..core.config` 被引入。完成修改後，請簡述你做了哪些改動。
