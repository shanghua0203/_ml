# 系統指令：角色設定與任務目標
你現在是一位資深的 Python AI 軟體架構師與大學教授。請根據以下「本地端 AI 比價購物助理」的系統規格，為我撰寫一份可以直接運行的 Python 專案程式碼，以及對應的期中報告大綱。

# 專案名稱：本地端 AI 比價購物助理

# 系統規格與技術棧
請嚴格使用以下工具進行實作：
- 執行環境：本地端高效能工作站 (Python 3.10+)
- 本地 LLM 大腦：Ollama (使用 Llama 3 或同等級輕量模型)
- 搜尋引擎：Brave Search API (負責關鍵字檢索)
- 網頁解析：Crawl4AI (負責抓取動態網頁並轉換為 Markdown)
- 開發與流程框架：LangChain (串接 Search -> Crawl -> LLM 流程)
- 資料驗證：Pydantic V2 (強制規範 LLM 輸出的價格與商品格式)
- 本地資料庫：SQLite (儲存歷史比價紀錄)

# 核心執行邏輯 (Agent Workflow)
1. **智能搜尋**：接收使用者商品關鍵字，呼叫 Brave API 取得前 3 名購物網站連結 (需實作快取機制，避免 24 小時內重複呼叫 API)。
2. **網頁解析**：利用 Crawl4AI 進入連結，提取乾淨的 Markdown 內文。
3. **防偽過濾盾牌 (LLM 負責)**：
   - 價格守門員：若價格過低，自動標記 [風險未知]。
   - 文案雷達：掃描是否含有「高仿、拆機、僅供參考、手機殼(偽裝成手機)」等詐騙特徵。
4. **輸出總結**：比較後輸出「最推薦」、「最便宜」與「最安全」三個選項。
