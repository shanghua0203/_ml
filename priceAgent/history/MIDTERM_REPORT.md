# 期中報告大綱：本地端 AI 比價購物助理

## 1. 專案簡介

### 1.1 專案名稱
本地端 AI 比價購物助理

### 1.2 專案目標
開發一個完全在本地端運行的 AI 比價購物助理，利用 LLM 技術協助使用者進行商品比價，並具備防偽過濾功能，避免使用者落入詐騙陷阱。

### 1.3 核心價值
- **隱私保護**：所有資料儲存在本地端，無需上傳商品資訊至外部伺服器
- **成本效益**：不需雲端運算資源，降低長期運行成本
- **即時性**：本地 LLM 無需等待雲端回應，處理速度更快

## 2. 系統架構

### 2.1 技術棧

| 執行環境 | Python 3.10+ | 穩定且強大的語言支援 |

## 3. 核心模組實作

### 3.1 資料模型 (Pydantic V2)

```python
class Product(BaseModel):
    name: str
    price: float
    url: str
    source: str
    original_price: Optional[float]
    discount_rate: Optional[float]

class FraudDetectionResult(BaseModel):
    url: str
    has_suspicious_text: bool
    suspicious_keywords: list[str]
    price_analysis: Optional[PriceAnalysis]
```

### 3.2 快取機制

- 使用 SQLite 儲存搜尋結果快取
- 快取期限：24 小時
- Hash key：使用 MD5 產生唯一标识

### 3.3 防偽過濾機制

#### 價格守門員規則
| 價格範圍 | 風險等級 | 處理方式 |
|---------|---------|---------|
| < 最低門檻 × 50% | high | 標記為高風險，不建議購買 |
| < 最低門檻 | medium | 標記為中風險，提示使用者注意 |
| ≥ 最低門檻 | low | 正常價格 |

#### 可疑關鍵字列表
- 高仿、拆機、僅供參考
- 手機殼(偽裝成手機)、樣機、展示機
- 仿冒、山寨、A貨、B貨、C貨
- 特供、贈品、瑕疵

### 3.4 評分引擎

```python
安全分數 = 100 - (風險等級懲罰) - (可疑文字懲罰)
價格分數 = 100 - (遠離中位數的懲罰)
綜合分數 = 安全分數 × 60% + 價格分數 × 40%
```

## 4. 系統特色

### 4.1 本地端運行
- 所有資料處理在本地完成
- 無需上傳商品資訊
- 隱私性高

### 4.2 快取機制
- 搜尋結果 24 小時快取
- 減少 API 呼叫次數
- 提升效能

### 4.3 智能推薦
- **最推薦**：綜合分數最高的商品
- **最便宜**：價格最低的商品
- **最安全**：安全分數最高的商品
